## 新建用户级 Skill：github-push

- 位置：`~/.workbuddy/skills/github-push/`（`SKILL.md` + `scripts/gh_push.py`）
- 用途：把本地 Python 项目发布到 GitHub 公开仓库
- 三个子命令：`doctor`（体检）/ `scan`（敏感信息扫描，只读）/ `push`（两阶段发布）
- 关键设计决策：
  - `push` 默认只预演，必须显式加 `--yes` 才真正执行（公开仓库不可撤回）
  - 高危敏感信息命中直接中止（退出码 2），需 `--allow-secrets` 才绕过
  - 认证统一走 `gh auth login`，拒绝把 token 写进 remote URL；执行时自动清除历史遗留的内嵌凭据
  - 退出码约定：0 成功 / 1 一般错误 / 2 命中敏感信息 / 3 待确认 / 4 未登录
  - 额外加了 `--local-only`（只 init/gitignore/commit，不推远端），既可离线整理，也用于覆盖本地执行路径的测试
- 测试情况：doctor / scan / push 预演 / push --local-only 全部实测通过；预演前后 `git status` 与 `reflog` 完全一致，确认零副作用
- 已知局限：真实推送路径（建仓 + push）尚未端到端验证，因为本机 `gh` 未登录
