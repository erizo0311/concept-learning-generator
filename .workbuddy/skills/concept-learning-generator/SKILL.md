# Concept Learning Generator · 概念学习资料生成器

## 一、这个 Skill 是干什么的

`concept-learning-generator` 是一个**知识辅助生成工具**。你给我一个想学的新概念，
我帮你把它整理成一份**结构化、可自测、可核对**的学习资料，而不是一段零散的科普。

它把「**如何学习一个陌生概念**」沉淀成一套可复用的流程，你可以拿它去学任何概念，
而不只是作业里要求的三个。

---

## 二、适用场景

| 场景 | 是否适合 | 说明 |
|------|:---:|------|
| 想快速入门一个陌生概念 | ✅ | 自动生成结构化解释 + 拆解 |
| 备考 / 面试前需要概念框架 | ✅ | 生成核心问题 + 自测题 |
| 学完技术想写总结笔记 | ✅ | 输出可直接保存的学习页 |
| 需要「同一件事」的多个角度 | ✅ | 概念辨析模块专门处理 |
| 只想要一句话解释 | ❌ | 本 Skill 输出的是结构化长文档 |

> 本 Skill 面向「**深度理解**」，不做「一句话科普」。

---

## 三、输入信息（你要告诉我什么）

```yaml
# 必填
concept: "要学习的概念名称，例如：Agent、大模型的上下文、Skill、Transformer、决策树"

# 选填（用于定制）
context_hint: "一句话背景说明（例如：为了理解 AI Agent 的工作原理）"
level: "难度偏好：入门 / 进阶（默认：进阶）"
output_style: "输出风格：HTML 学习页 / Markdown 笔记（默认：HTML）"
```

**最小输入示例**

```
学习「Agent」这个概念
```

**带定制的输入示例**

```
概念：大模型的上下文
背景：我想搞懂 prompt 里为什么塞不进去太长的内容
难度：进阶
```

## 四、生成步骤（自动化流水线）

拿到一个概念后，按以下 6 步依次产出，每一步都有明确产出物：

1. **定义与定位**
   → 用一句话给出「我理解的概念」，说明它在整个技术生态里的位置（上/下游、依赖谁、被谁依赖）。

2. **拆解核心机制**
   → 列出它的**组成模块 / 运行流程**，尽量用「输入 → 处理 → 输出」的结构，辅以 Mermaid 或说明性列表。

3. **找真实应用场景**
   → 给出 **1 个具体可感知的应用案例**（用到这个概念的真实产品/系统），说明它在这个场景里扮演什么角色。

4. **做概念辨析**
   → 找出**最容易和它混淆的专业名词/边界问题**，逐条对比「它 ≠ 什么」「什么情况不算它」。

5. **生成核心问题与自测题**
   → 先提炼 3 个「弄懂这个概念的必答问题」，再出 3~5 道自测题（含参考答案），用于检验是否真懂。

6. **沉淀参考来源**
   → 汇总**可核查、真实存在**的资料来源链接（官方文档 / 论文 / 权威博客），**禁止伪造 URL**。

> 每一步产出后都执行一次**自检**（见第七节），不合格就返工这一步，再继续下一步。

## 五、输出结构（最终交付物）

### 5.1 7 大模块内容（Markdown 源稿）

| # | 模块 | 内容要点 | 必须包含 |
|:-:|------|---------|:---:|
| 1 | 学习目标 | 学完后你能做什么（3 条，动词开头） | ✅ |
| 2 | 核心问题 | 弄懂这个概念必须先回答的 3 个问题 | ✅ |
| 3 | 结构化解释 | 个人理解 + 核心机制 + 组成（可用图/表） | ✅ |
| 4 | 应用案例 | 1 个真实场景，说清概念的角色 | ✅ |
| 5 | 概念辨析 | 易混淆点 / 边界条件（对比式） | ✅ |
| 6 | 自测问题 | 3~5 道题 + 参考答案 | ✅ |
| 7 | 参考来源 | 真实可核查的链接列表 | ✅ |

### 5.2 HTML 学习页（渲染成品）

- 单文件 HTML，自带 CSS，可直接双击在浏览器打开
- 顶部标题栏显示概念名 + 「个人学习资料」
- 7 大模块依次分区排版，带导航锚点
- 区分「正文」和「我的核对备注」，体现人工核查痕迹

## 六、资料来源要求（硬性规定）

1. **必须真实可核查**：链接要能点开、内容真实，优先使用：
   - 官方文档（如 OpenAI、Anthropic、LangChain、WorkBuddy 官方文档）
   - 权威论文（arXiv、顶会）
   - 知名技术博客 / 官方教程
2. **禁止伪造**：绝不能编造 URL、DOI、书名或作者。
3. **注明用途**：每个来源旁标注「用于佐证哪一点」，方便核验。
4. **尽量给出可验证的具体页面**，不要只丢一个站首页。

---

## 七、自检要求（交付前必查）

生成过程或完成后，逐条自检以下问题，**任一不合格即返工对应模块**：

- [ ] **真实**：资料来源链接是真实存在、可访问的吗？没有伪造吧？
- [ ] **原创理解**：结构化解释是「我理解」的版本吗？没有整段粘贴 AI 原文吧？
- [ ] **结构齐全**：7 大模块都在吗？每模块的「必须包含」项都达标了吗？
- [ ] **能复用**：换个新概念（如「Transformer」）重跑，流程依然成立吗？没有写死只适用三个概念吧？
- [ ] **目标达成**：看完这份资料，一个初学者能复述并回答自测题吗？
- [ ] **边界清楚**：概念辨析里说清了"它不是什么"吗？

## 八、典型使用示例

**示例 1：生成「Agent」的学习资料**

```
概念：Agent
背景：我想理解 AI Agent 到底是什么、能干什么
```

→ 自动生成 `learning-materials/agent.html`，内含 Agent 的定义、核心机制（感知→规划→行动→反思）、
应用场景（自动写代码、多智能体协作）、与「工作流/RPA」的辨析、自测题和来源。

**示例 2：换个概念再跑一次（验证可复用性）**

```
概念：Transformer
背景：深度学习中的自注意力架构
```

→ 流程完全复用，自动生成 `learning-materials/transformer.html`，无需修改本 Skill。
